Kept in this browser tab only (sessionStorage) and sent to this proxy only.

The admin API only answers this machine

Without PROXY_API_KEY, account controls accept direct requests from localhost only. Requests relayed by a reverse proxy (X-Forwarded-For or Forwarded) count as remote.

To manage accounts from another host, set one of these and restart the proxy:

  • PROXY_API_KEY then enter the key on this page.
  • PROXY_ADMIN_ALLOW_REMOTE=1 to allow remote admin without a key.

Browsers on another origin also need that origin listed in PROXY_CORS_ORIGINS.
